# Голосовой помощник: микрофон на каждой странице

Кнопка с микрофоном в правом нижнем углу любой страницы. Нажали, сказали («выключи свет», «убери на кухне», «режим уборки двойной»), помощник сделал и ответил голосом и текстом. Управляет камерой, лентами света, пылесосом и телевизором через их собственные API.

Решения и почему так: [ADR 0020](adr/0020-voice-assistant.md).

## Как это устроено

```
микрофон (браузер, ru-RU)
   → текст
   → POST /api/assistant
        1. выученные фразы        (data/assistant/learned.json)
        2. правила                (backend/src/quick.ts)         ← почти всё повседневное
        3. модель с инструментами (Ollama или Claude)            ← только остальное
   → внутренние вызовы /api/* с токеном вызвавшего
   → ответ текстом → озвучка (голос браузера)
```

- **Распознавание речи и озвучку делает браузер** (Web Speech API). Chrome отправляет звук на распознавание в Google; в Anthropic и на сервер уходит только текст фразы. В Safari и Firefox распознавание нестабильно, но поле «or type a command» работает везде.
- **Помощник действует через собственный HTTP API** (`app.inject` с токеном вызвавшего), а не через объекты сервисов. Поэтому работают все проверки маршрутов (пылесос занят, телевизор не сопряжён), и он умеет не больше, чем человек с токеном.
- **Правила стоят перед моделью.** Маленькая локальная модель бывает ненадёжной: говорила «выключаю свет» и ничего не делала. Правила мгновенные, бесплатные и одинаковые каждый раз. Модель получает только то, что правила не разобрали целиком.
- Фраза перед разбором приводится к простому виду (`plain`): строчные буквы, без точки на конце. Распознавание отдаёт «Выключи свет.», и на такую запись маленькая модель не вызывала инструмент.

## Настройка

В `backend/.env`:

| Переменная | По умолчанию | Смысл |
|------------|--------------|-------|
| `ASSISTANT_PROVIDER` | `ollama`; `anthropic`, если задан `ANTHROPIC_API_KEY` | чем помощник понимает необычные фразы |
| `ASSISTANT_MODEL` | `qwen3:8b` (ollama), `claude-opus-5-5` (anthropic) | модель |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | где работает Ollama |
| `TTS_PIPER` | включён, если Piper установлен | `false` выключает нейроголос (останутся голоса браузера) |
| `TTS_CLONE`, `CLONE_PYTHON`, `CLONE_REFERENCE`, `CLONE_PORT` | включён, если есть `backend/venv-mlx` (Chatterbox на MLX: фраза делается примерно за время её звучания) и `backend/data/voice/reference.wav`; порт `5056` | голос «Оля» (клон, [ADR 0023](adr/0023-cloned-assistant-voice.md)) становится главным, при сбое остаются другие голоса Piper, если они лежат в `backend/models/piper/`, иначе голос браузера; `TTS_CLONE=false` выключает. Ответы кэшируются в `backend/data/voice/cache/`. Первая новая фраза идёт секунды, повторная мгновенно |
| `PIPER_PYTHON`, `PIPER_MODEL`, `PIPER_PORT` | `venv-piper/bin/python`, `backend/models/piper/ru_RU-denis-medium.onnx`, `5055` | где Piper, главный голос, порт его сервера (только `127.0.0.1`) |
| `ANTHROPIC_API_KEY` | пусто | ключ, если нужен Claude. Получить: https://console.anthropic.com → Settings → API Keys (API оплачивается отдельно от подписки) |

Без настройки кнопка микрофона видна всегда (по умолчанию провайдер `ollama`), а правила работают и без модели: если Ollama не запущен, фразы, которые разбирают правила, всё равно выполняются.

### Бесплатная локальная модель (Ollama)

```bash
brew install ollama
ollama pull qwen3:8b        # около 5 ГБ; на Mac с 24 ГБ отвечает за 1-1,5 с
ollama serve                # или: brew services start ollama (запуск при входе в систему)
```

`qwen3:8b` понимает русский и вызов инструментов. Для редких фраз надёжнее `qwen3:14b` (около 9 ГБ, чуть медленнее): `ollama pull qwen3:14b` и `ASSISTANT_MODEL=qwen3:14b`. Размышление у Qwen выключено (`think: false`), иначе каждая простая команда ждала бы секунды.

### После правок

Бэкенд нужно перезапустить: `./camera.sh restart backend`. Без этого работает старый код.

## Что понимают правила

Фраза может состоять из нескольких команд («включи свет и запусти пылесос», через «и», запятую, «потом»). Если хоть одна часть неизвестна, всю фразу берёт модель.

| Что | Примеры | Действие |
|-----|---------|----------|
| **Свет** | «включи свет», «выключи свет», «погаси», «потуши», «поярче», «приглуши», «сделай свет синим», «включи ленту» | обе ленты разом. Цвета: красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, розовый, белый |
| **Камера** | «поверни камеру налево», «камера вправо», «вверх», «вниз», «сильно налево» | поворот на 2 шага (4 при «сильно») |
| **Громкость ТВ** | «громче», «погромче», «тише», «потише», «намного громче», «выключи звук», «включи звук» | 3 нажатия (6 при «намного»), mute одним нажатием |
| **Питание ТВ** | «включи телевизор», «выключи телевизор» | клавиша питания (переключатель) |
| **Приложения ТВ** | «открой ютуб», «нетфликс», «прайм», «дисней», «твич», «призма» | запуск приложения |
| **Пылесос: действия** | «запусти пылесос», «убери», «пауза», «останови», «пылесос домой», «найди пылесос», «очисти бак» | старт, пауза, остановка, на базу, подать голос, опустошить бак |
| **Пылесос: комнаты** | «убери на кухне», «пропылесось в спальне» | уборка названных комнат (по сохранённой карте, с учётом склонения). Без названия комнаты запускается вся уборка |
| **Режим уборки** | «мокрая уборка», «режим мытья», «сухая уборка», «двойной», «сухая и мокрая», «запусти мокрую уборку» | сухая, мытьё, двойная. С «запусти» ещё и начинает |
| **Мощность** | «мощность турбо», «режим всасывания strong», «пылесос потише» | quiet, standard, strong, turbo. Принимаются русские и английские слова |
| **Вода** | «вода высоко», «больше воды», «вода low», «вода средняя» | low, medium, high |
| **Карта** | «обнови карту», «перерисуй карту» | обновление карты из облака Xiaomi (несколько секунд) |

Опасное голосом недоступно: сброс счётчиков деталей, сопряжение телевизора, удаление клипов, зоны движения, настройки вроде детского замка. Закрыть все приложения на телевизоре можно («закрой все приложения», нужен `TV_ADB`), одно по имени нельзя.

### Распознавание ошибается

Браузер слышит «очисти бак» как «очись баг». Поэтому правила сопоставляют на слух: для бака годятся «бак», «бачок», «баг», «бэк», «back», «мусор». Английские слова уровней («Turbo», «High») понимаются наравне с русскими. Если фраза не сработала, смотрите, что именно услышал браузер: это написано сверху в панели.

### Уточняющие вопросы

Когда названа настройка, но не значение, помощник спрашивает, и следующая фраза считается ответом:

| Вы сказали | Он спрашивает | Ответ |
|------------|---------------|-------|
| «режим всасывания» | «Какую мощность всасывания: тихо, стандарт, сильно или турбо?» | «турбо» |
| «режим уборки» | «Какой режим уборки: сухая, мытьё или двойная?» | «двойной» |
| «уровень воды» | «Сколько воды: мало, средне или много?» | «много» |
| фраза про пылесос, которую никто не разобрал | «Что сделать с пылесосом: запустить, домой, найти, режим уборки, мощность или вода?» | любая команда |

После вопроса снова нажмите на микрофон.

## Как помощник «учится»

Веса модели мы не дообучаем: на фразах одного дома это дало бы меньше, чем правила и выученные фразы.

1. **Remember this phrase.** Если модель сама справилась с необычной фразой (например, «включи ночник»), в панели появляется эта кнопка. Нажали, и фраза сохраняется в `data/assistant/learned.json` вместе с действиями. Дальше она выполняется мгновенно и без модели. То, что сохраняется, берётся с сервера (последний успешный запуск этой фразы), а не присылается страницей. Лимит: 500 фраз.
2. **Журнал** `data/assistant/journal.jsonl`: каждая фраза, кто её понял (`rules`, `learned`, `model`), получилось ли и что ответили. Фразы с `model` и с ошибками показывают, какие правила стоит дописать.
3. **Разбор журнала.** `cd backend && npm run journal` прогоняет все фразы через текущие правила и печатает: что уже исправлено правилами, где помощник услышал сам себя (эхо), предложения (фраза не сработала, а следующей вы сказали то, что правила понимают) и пробелы (следующие правила). `npm run journal -- --apply` выучивает предложения, повторившиеся хотя бы дважды; потом перезапустите бэкенд, иначе он перезапишет файл своей копией.
   В панели помощника то же самое видно без терминала: при открытии она показывает до пяти предложений вида «хочу темноту» = «выключи свет». Нажали, и фраза выучена сразу (перезапуск не нужен). Шаги берёт сервер, страница присылает только фразу.
4. **Как улучшать.** Попользуйтесь голосом несколько дней, затем попросите посмотреть журнал: фразы, которые понимала только модель, превращаются в правила в `backend/src/quick.ts` с тестом.

4. **Самообучение (без кнопок).**
   - Модель справилась с фразой **дважды одинаково** (те же инструменты и параметры): фраза выучена сама. Ответ тогда приходит с `learned: true`, панель пишет «Запомнил».
   - Модель ничего не сделала и ответила «не могу» / «нет инструмента»: помощник спрашивает «Не поняла «…». Что вы имели в виду?». Следующая фраза, которая сработала (в течение 60 секунд, один раз), выучивается как значение непонятой («помой дом» → «запусти пылесос»).
   - Сбой, исправленный вами следующей фразой одинаково **два раза**, выучивается сам (то, что раньше делал `npm run journal -- --apply`).
   - «Нет», «не то», «отмена» сразу после ответа: последняя догадка отбрасывается, а фраза, выученная меньше двух минут назад, забывается.

Забыть выученную фразу: `POST /api/assistant/forget {"text":"включи ночник"}`.

## Голос ответа

Голос Denis (Piper) удалён с диска по просьбе владельца; главный голос теперь «Оля» (клон, [ADR 0023](adr/0023-cloned-assistant-voice.md)), без неё остаются голоса браузера. Ниже про Piper как он был устроен: другие голоса Piper кладутся в `backend/models/piper/`.

Помощник отвечает голосом **Piper**: бесплатный нейроголос, который работает на этом Mac без интернета. Если Piper не установлен, отвечают русские голоса браузера (кроме Milena).

В панели помощника есть список **Voice** и ползунок **Speed**; выбор запоминается в браузере. Голоса Piper подписаны «(neural, Piper)» и стоят первыми.

### Установка Piper (один раз)

```bash
cd ~/WebstormProjects/xiaomi-camera
python3.12 -m venv venv-piper                      # нужен Python 3.12 (на новых версиях колёс может не быть)
venv-piper/bin/python -m pip install piper-tts flask
mkdir -p backend/models/piper && cd backend/models/piper
B=https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU
curl -LO $B/denis/medium/ru_RU-denis-medium.onnx   # мужской
curl -LO $B/denis/medium/ru_RU-denis-medium.onnx.json
```

Сервер Piper бэкенд запускает и останавливает сам: при первой озвучке (около секунды) и дальше держит голос в памяти (следующие фразы за десятки миллисекунд). Он слушает только `127.0.0.1`, наружу бэкенд отдаёт лишь `/api/tts` с токеном. После установки перезапустите бэкенд: `./camera.sh restart backend`.

## API

Все пути требуют `Authorization: Bearer <API_TOKEN>`.

| Метод | Путь | Что делает |
|-------|------|------------|
| GET | `/api/assistant` | `{configured}`: включён ли помощник |
| POST | `/api/assistant` | `{text, history?}` (`text` до 500 знаков; `history`: до 8 последних реплик `{role, content}`) → `{reply, actions, learnable?, learned?}`. `actions`: что сделано (`tool`, `input`, `ok`) |
| POST | `/api/assistant/learn` | `{text}`: запомнить фразу, которую только что выполнила модель (409, если запоминать нечего) |
| POST | `/api/assistant/forget` | `{text}`: забыть выученную фразу |
| GET | `/api/assistant/journal` | `{learned, recent}`: выученные фразы и последние 100 записей журнала |
| GET | `/api/tts` | `{piper, default, voices}`: есть ли нейроголос и какие голоса лежат в `backend/models/piper/` |
| POST | `/api/tts` | `{text, speed?, voice?}` (`text` до 400 знаков, `speed` 0,5..2) → аудио WAV. 404, если Piper не установлен; 502, если не ответил (страница тогда говорит голосом браузера) |

Инструменты модели (`assistant.ts`): `camera_move`, `lights_list`, `lights_set`, `vacuum_status`, `vacuum_action`, `vacuum_mode`, `vacuum_suction`, `vacuum_water`, `vacuum_map_refresh`, `vacuum_rooms`, `vacuum_clean_rooms`, `tv_key`, `tv_app`, `tv_sources`, `tv_source`.

## Если что-то не работает

| Симптом | Причина и что делать |
|---------|----------------------|
| кнопки микрофона нет | выключен помощник (`ASSISTANT_PROVIDER=anthropic` без `ANTHROPIC_API_KEY`) или старый сервер: `./camera.sh restart backend` |
| «The browser has no access to the microphone» | разрешите микрофон в адресной строке (нужен `localhost` или HTTPS) |
| «Ollama is not answering: start it (ollama serve)» | Ollama не запущен: `ollama serve` или `brew services start ollama` |
| «Ollama has no model …: run `ollama pull …`» | модель не скачана |
| «the Anthropic key is wrong or missing» | неверный ключ в `.env` |
| «Не получилось выполнить команду. Скажите ещё раз» | модель сказала, но ничего не сделала даже после повторной попытки; скажите чуть иначе или попросите добавить правило |
| «Не получилось: …» | сама команда не прошла (пылесос занят или на ошибке, телевизор выключен): после двоеточия причина словами |
| голос браузера вместо Piper | Piper не установлен или не ответил: проверьте `venv-piper`, файлы голоса в `backend/models/piper/` и лог бэкенда (`piper: …`) |
| фраза услышана неверно («очись баг») | это распознавание браузера; нужно добавить вариант в правила |
| «Remember this phrase» не появляется | запомнить можно только то, что сделала модель и что прошло успешно |

## Что проверено

Тесты: бэкенд 389, веб 137 (подменённая модель и подменённые устройства). Вживую проверено на этом Mac: цепочка фраза → Ollama → API; включение света и опустошение бака на настоящих устройствах. Остальные команды проверены на подменённых вызовах. Piper проверен вживую: голос Denis синтезирует фразу, повторная занимает десятки миллисекунд. Распознавание речи и проигрывание в браузере зависят от Chrome и на тестах не проверяются.

## Чего нет

- Слова-пробуждения («эй, дом») и работы без нажатия кнопки.
- Автоматического прослушивания ответа после вопроса.
- Локального распознавания речи (Whisper): речь распознаёт Chrome (звук уходит в Google).
- Голосом недоступны зоны, клипы, снимки, расписание и сброс деталей пылесоса.
