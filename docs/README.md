## Решения (ADR)

Каждое решение записано коротко: зачем, что решили, как проверили, какие минусы остались. Нумерация по порядку принятия.

| № | Тема | Одной строкой |
|---|------|---------------|
| [0001](adr/0001-signed-media-urls.md) | Подписанные ссылки на файлы | Токен только в заголовке; клипы и снимки открываются по ссылке с подписью и сроком, клип стримится |
| [0002](adr/0002-auth-lockout-and-security-headers.md) | Блокировка подбора и заголовки | 10 неверных токенов за минуту блокируют адрес; строгая CSP, без `Referer` |
| [0003](adr/0003-motion-lighting-filter-storage-limit-localhost.md) | Освещение, диск, адрес | Смена освещения не движение; лимит размера клипов; слушаем только этот Mac |
| [0004](adr/0004-ptz-queue-and-auto-reconnect.md) | Очередь PTZ и переподключение | Поворот по одному; видео восстанавливается само; джойстик отпускается |
| [0005](adr/0005-push-notifications.md) | Пуш-уведомления | Expo Push, сводка при частых событиях, что уходит из дома; Expo или PWA |
| [0006](adr/0006-single-launcher.md) | Запуск одним файлом | `camera.sh` запускает и останавливает всё |
| [0007](adr/0007-damaged-stream-and-frozen-stream.md) | Повреждённый и замёрзший поток | Потеря пакетов не считается движением; замерзание закрывает событие и перезапускает ffmpeg |
| [0008](adr/0008-motion-zones.md) | Зоны движения | «Игнорировать» и «только здесь», живая шкала уровня |
| [0009](adr/0009-system-panel.md) | Панель System | Состояние go2rtc, картинки, диска, пушей словами |
| [0010](adr/0010-episodes-and-day-filter.md) | Эпизоды и фильтр по дню | Близкие клипы в одну историю |
| [0011](adr/0011-privacy-zones.md) | Приватные зоны | Чёрное в живом виде, снимках и превью; записи не меняются; при сбое кадр не отдаётся |
| [0012](adr/0012-object-detection.md) | Распознавание объектов | YOLOX-Tiny ставит метки «человек / машина / животное»; клип, где ничего не найдено, удаляется (`DETECT_DISCARD_EMPTY`) |
| [0013](adr/0013-mi-home-sign-in-and-adding-cameras.md) | Вход в Mi Home и добавление камеры | Экран «Cameras» вместо страницы go2rtc; источник потока берёт бэкенд, не браузер |
| [0014](adr/0014-backend-structure.md) | Структура бэкенда | Корень сборки, модули маршрутов, `ClipBuilder`, общий тестовый конфиг; поведение не менялось |

## Как добавить решение

Новый файл `adr/NNNN-короткое-имя.md` с разделами: контекст, решение, проверка (что проверено и что **нет**), последствия.
Добавьте строку в таблицу выше и отметьте пункт в [`ROADMAP.md`](../ROADMAP.md).
