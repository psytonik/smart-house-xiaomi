# Пылесос (Dreame L10 Plus, `dreame.vacuum.p2028a`)

Страница `/vacuum` управляет роботом по локальной сети, без облака: протокол miIO (UDP, порт 54321) и свойства MIoT. Облако Xiaomi нужно только для карты, позиции робота и истории уборок.

Решения и почему так: [ADR 0019](adr/0019-vacuum-page-and-safe-writes.md). План и состояние: раздел «Пылесос: roadmap» в [`ROADMAP.md`](../ROADMAP.md).

## Настройка

В `backend/.env`:

| Переменная | По умолчанию | Смысл |
|------------|--------------|-------|
| `VACUUM_IP` | нет | адрес робота (закрепите его в роутере) |
| `VACUUM_TOKEN` | нет | токен miIO из аккаунта Xiaomi. Хранить только в `.env`, не в чате и не в git |
| `VACUUM_PORT` | `54321` | порт miIO |
| `VACUUM_WATCH_MS` | `60000` | как часто сервер смотрит на робота ради пушей (уборка закончена, ошибка, севшая батарея, износ деталей); `0` выключает |
| `VACUUM_LEVELS_DELAY_MS` | `5000` | через сколько после старта возвращать выбранные силу и воду (робот сбрасывает их на максимум) |
| `VACUUM_MAP_POKE_MS` | `20000` | не чаще, чем раз в это время просить робота выгрузить карту |

Без `VACUUM_IP` и `VACUUM_TOKEN` страница показывает, как настроить. Для карты, позиции и истории один раз войдите в Xiaomi: `cd backend && node_modules/.bin/tsx --env-file=.env ../tools/xiaomi-cloud.ts login` (пароль не сохраняется, в `backend/data/xiaomi-session.json` лежат только ключи сессии, режим 600).

После правок бэкенда его нужно перезапустить: `launchctl kickstart -k gui/$(id -u)/com.psytonik.xiaomi-camera` (подробности в [`docs/tv.md`](tv.md#перезапуск-после-правок)). Устаревший сервер отвечает на новые маршруты 404, страница в этом случае сама пишет «the server is older than this page».

## Что есть на странице

Раскладка: слева робот и его настройки, справа карта, уход, история и настройки робота (на узком экране одна колонка).

- **Робот:** заряд кольцом, состояние словами (уборка, пауза, возвращается, заряжается, опорожняет контейнер, обновляется, ошибка), последняя или текущая уборка (м² и минуты), вид уборки (весь дом, комнаты, зона, спот).
- **Кнопки:** «Start cleaning» / «Pause» / «Resume», «Stop» (завершает уборку насовсем, с подтверждением), «Go home», «Find the robot», «Empty the bin» (опорожнить контейнер на станции).
- **Ошибки словами:** код ошибки расшифровывается в название и совет, красной рамкой на странице и в пуше. Таблица в `backend/src/vacuumErrors.ts` (коды из Tasshack/dreame-vacuum, формулировки наши); неизвестный код показывается как «Error N».
- **Cleaning settings:** режим (Sweeping, Mopping, Sweep and mop), сила всасывания (Quiet, Standard, Strong, Turbo), вода (Low, Medium, High). Каждое значение записывается и читается обратно: если робот ответил «да», но оставил своё (включён Customized Cleaning), страница показывает причину и реальное значение.
- **Floor plan:** карта из облака Xiaomi, перерисовывается при открытии, раз в 30 секунд во время уборки и после неё; позиция робота и след во время уборки.
- **Care:** износ главной щётки, боковой щётки, фильтра и датчиков (проценты и часы), кнопки «Replaced» и «Cleaned» (сбрасывают счётчик, с подтверждением), итоги: уборок, площадь, время, первая уборка.
- **Recent cleanings:** последние 5 уборок из облака, «Show all N».
- **Robot settings:** переключатели (Resume after charging, Carpet boost, Obstacle avoidance, Child lock, Do not disturb), часы «не беспокоить», громкость (ползунок; робот говорит на новой громкости), чувствительность ковра, как часто станция сама опорожняет контейнер (после каждой, второй или третьей уборки). Только показ: Customized cleaning.
- **Schedule:** расписание, хранящееся в роботе (только чтение; меняется в приложении Dreame). Карточка появляется, если в роботе есть задачи.
- **Rooms:** уборка выбранных комнат по порядку выбора. Появляется, только если у робота больше одной комнаты (их размечают в приложении Dreame). **Не проверено на роботе.**
- **About the robot:** модель, прошивка (свёрнуто).

Пуши (`VacuumWatcher`): уборка закончена, робот остановился с ошибкой (с названием и советом), батарея села вдали от станции, деталь износилась.

## API

Все маршруты требуют токен приложения (`Authorization: Bearer …`). Ответ 404 «not configured», если робот не настроен; 502 с причиной, если робот не принял команду; 409, если команда сейчас невозможна.

| Метод | Путь | Что делает |
|-------|------|------------|
| GET | `/api/vacuum` | состояние: `battery`, `mode`, `statusCode`, `areaM2`, `minutes`, `cleaningMode`, `suction`, `water`, `task`, `fault {code,title,hint}`, `dustStation {autoEmpty,ready,emptying,limited}`, `model`, `firmware` (или `configured:false`, `reachable:false`) |
| POST | `/api/vacuum` | `{action}`: `start`, `pause`, `stop`, `dock`, `find`, `empty`. `empty`: 409, если робот не на станции, станция занята или её нет |
| POST | `/api/vacuum/mode` | `{mode}`: `sweeping`, `mopping`, `both` |
| POST | `/api/vacuum/suction`, `/water` | `{level}`: `quiet…turbo` и `low…high`; с чтением обратно |
| GET | `/api/vacuum/care` | износ деталей и итоги |
| POST | `/api/vacuum/reset` | `{part}`: `mainBrush`, `sideBrush`, `filter`, `sensor` |
| GET | `/api/vacuum/settings` | все настройки робота; не ответившие пропускаются, если ни одна не ответила, 502 |
| POST | `/api/vacuum/setting` | `{name, on}`: `resumeCleaning`, `carpetBoost`, `obstacleAvoidance`, `childLock`, `dnd` |
| POST | `/api/vacuum/volume` | `{level}` 0-100 |
| POST | `/api/vacuum/carpet` | `{level}`: `low`, `medium`, `high` |
| POST | `/api/vacuum/auto-empty` | `{every}`: 1, 2 или 3 |
| POST | `/api/vacuum/dnd-hours` | `{from, to}`, `"HH:MM"` |
| GET | `/api/vacuum/schedule` | расписание из робота, только чтение |
| GET | `/api/vacuum/map` | картинка плана (PNG) |
| POST | `/api/vacuum/map/refresh` | перерисовать план из карты в облаке |
| GET | `/api/vacuum/live` | позиция робота и след (в клетках плана) |
| GET | `/api/vacuum/history` | уборки из облака, новые первыми |
| GET | `/api/vacuum/rooms` | комнаты сохранённой карты (пусто, пока комнат меньше двух) |
| POST | `/api/vacuum/clean-rooms` | `{rooms: [номера]}` по порядку; 409, если робот занят |

## Как это устроено внутри

| Файл | Что в нём |
|------|-----------|
| `backend/src/miio.ts` | miIO: рукопожатие, шифрование, запросы |
| `backend/src/vacuum.ts` | свойства и действия MIoT, чтение состояния, настройки, уход, расписание, команда по комнатам |
| `backend/src/vacuumErrors.ts` | коды ошибок и советы |
| `backend/src/vacuumMap.ts`, `vacuumRooms.ts` | разбор и рисование карты, комнаты |
| `backend/src/vacuumWatcher.ts`, `vacuumLevels.ts` | пуши; возврат силы и воды после старта |
| `backend/src/xiaomiCloud.ts` | подписанные запросы к облаку Xiaomi (файл карты, кадры, история) |
| `backend/src/routes/vacuum.ts` | маршруты |
| `web/src/components/VacuumPage.tsx` | страница |

Номера свойств MIoT, которые используются (siid/piid; `a` обозначает действие):

| Что | Номер |
|-----|-------|
| состояние, ошибка | 2/1, 2/2 |
| батарея | 3/1; «домой» 3/a1 |
| время, площадь уборки | 4/2, 4/3 |
| сила, вода | 4/4, 4/5 |
| вид задачи | 4/7 |
| продолжение после зарядки, ковёр, обход препятствий | 4/11, 4/12, 4/21 |
| режим уборки, Customized Cleaning, детский замок, чувствительность ковра | 4/23, 4/26, 4/27, 4/28 |
| start, pause, stop | 2/a1, 2/a2, 4/a2 |
| уборка комнат | действие 4/a1 со статусом 18 и списком `{"selects":[[комната,повторы,сила,вода,порядок]]}` |
| «не беспокоить» | 5/1 (true/false), 5/2, 5/3 |
| часовой пояс, расписание | 8/1, 8/2 |
| громкость, поиск робота | 7/1; 7/a2 (проба звука), 7/a1 (поиск) |
| щётки, фильтр | 9, 10, 11 (проценты и часы; сброс 9/a1, 10/a1, 11/a1) |
| итоги | 12/1…12/4 |
| станция | 15/1 (авто), 15/2 (частота), 15/3 (готова), 15/5 (опорожняет); команда 15/a1 |

Источник таблиц: Tasshack/dreame-vacuum (MIT, `types.py`, `translations/en.json`), для каждого номера значения проверялись чтением у нашего робота. Сервиса 27 (пылесборный мешок) и свойства 4/35 (предупреждения) у этого робота нет.

## Что проверено на роботе, а что нет

Проверено вживую: чтение состояния и настроек, смена режима, силы и воды, «Find the robot», запись громкости (с проверкой обратно), карта, позиция и след, история, износ деталей, статус «опорожняет» (15/5 = 1).

**Не проверено:** команда «Empty the bin», «Stop», сброс счётчиков, запись переключателей, чувствительности ковра, частоты и часов «не беспокоить», уборка комнат (в карте один сегмент) и значения вида задачи (4/7).

## Если что-то не так

- **«Couldn't update the map by itself … HTTP 404»:** в сессии Xiaomi мог остаться неверный регион. Регион сохраняется только после успешного скачивания (исправлено 2026-10-31), сессия сама возвращается на `cn`. Если не помогло: `tools/xiaomi-cloud.ts login` заново.
- **Новая кнопка не работает, ответ 404:** запущен старый сервер, перезапустите его.
- **Сила или вода «не берётся»:** включён Customized Cleaning (значения хранятся по комнатам); страница объяснит это в сообщении.
