# ADR 0010. Эпизоды и фильтр по дню

Дата: 2026-10-30. Статус: принято (идея из [исследования camera.ui](../research/cameraui.md): «не 14 клипов, а одна история»).

## Контекст

Человек, идущий по двору, даёт несколько клипов подряд. Список из десятков одинаковых карточек трудно просматривать, а найти вчерашнее событие можно только прокруткой.

## Решение (только веб-приложение, API не менялся)

- **Эпизод** (`src/episodes.ts`): клипы, где следующий начался не позже чем через `EPISODE_GAP_SEC` (180 с) после конца предыдущего, образуют один эпизод. Зазор считается от самого позднего конца, чтобы длинный клип не разрывал историю. Внутри эпизода клипы идут от старого к новому (как их смотреть), эпизоды в списке от нового к старому. Для эпизода считаются период, суммарная длина и сильнейшее движение.
- **Карточка** показывает превью первого клипа, число клипов значком и подпись «N clips, длительность». Одиночный клип выглядит как раньше.
- **Плеер** открывает первый клип эпизода; для эпизода из нескольких клипов есть «Previous», «Next» и «Clip i of n». Удаление клипа из эпизода переходит к следующему и обновляет список, закрытие происходит только когда клипов не осталось. Кнопки эпизода остаются и после удаления клипов.
- **Фильтр по дню** (All, Today, Yesterday, затем даты) по местному календарному дню. Не показывается, если все клипы из одного дня. Если выбранный день исчез из списка после обновления, показывается всё.

Зазор 180 секунд подобран от настроек детектора: `quietSec` 8 + запас после движения 4 + запас перед 6 даёт клипам «хвост»; по таймеру события с паузой в несколько минут чаще всего разные.

## Проверка

- `episodes.test.ts` (9): объединение и разделение, граница ровно в зазор, суммы, неверный порядок на входе, ключ дня (в том числе рядом с полночью), «Today» и «Yesterday», фильтр.
- `Clips.test.tsx` (6): число карточек, подпись «N clips», фильтр по дню, отсутствие фильтра при одном дне, листание клипов в плеере, одиночный клип без управления, удаление с переходом к следующему.
- Не проверено: вид в браузере на реальных данных (на момент проверки все 4 клипа были за один день, фильтр не показывался).

## Последствия

- Минус: список запрашивается с лимитом 48 клипов, поэтому «All» и дни ограничены ими. Для истории за неделю нужен постраничный запрос.
- Минус: зазор не настраивается. Если эпизоды получаются слишком длинными или короткими, значение меняется в `episodes.ts`.
