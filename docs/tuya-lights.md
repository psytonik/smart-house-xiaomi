# Лампочки Smart Life (Tuya)

Лампочки управляются напрямую по локальной сети, без облака: протокол Tuya 3.5 (TCP, порт 6668, AES-GCM), свой клиент в `backend/src/tuya.ts` без зависимостей. Облако нужно один раз, чтобы узнать **local key** каждой лампочки.

## Настройка

1. Найди ключи без аккаунта на iot.tuya.com (вход по QR из Smart Life, как в Home Assistant):
   ```
   python3 -m venv /tmp/tt && /tmp/tt/bin/pip install tuya-device-sharing-sdk "qrcode[pil]" tinytuya
   /tmp/tt/bin/python tools/tuya-keys.py <User Code> /tmp/tuya-out
   ```
   User Code: Smart Life → Я → шестерёнка → Аккаунт и безопасность → User Code. Скрипт сохранит `qr.png`; отсканируй его в Smart Life (Я → значок сканера) и подтверди вход. Скрипт напишет id, название и адрес каждого устройства; ключи лежат в `devices.json` рядом с QR. Потом удали папку.
2. Создай `backend/data/tuya-lights.json` (папка `data` не попадает в git):
   ```json
   [
     { "id": "kitchen", "name": "Кухня", "ip": "10.0.0.21", "deviceId": "…", "localKey": "…16 символов…" }
   ]
   ```
   `id` латиницей (`a-z`, `0-9`, `-`), по нему лампу находят API и помощник; `name` показывается в вебе и в ответах.
3. Перезапусти бэкенд (`./camera.sh restart backend`; при загруженном launchd-агенте go2rtc тоже перезапустится).
4. Закрепи за лампочками постоянные адреса в роутере (DHCP reservation).

Лампочки появляются в `GET /api/lights` и на странице `/lights`, управляются так же, как ленты: `POST /api/lights/:id` с `on`, `brightness`, `hue`, `saturation`. Помощник понимает «включи свет на кухне», «выключи в спальне»; «включи свет» без комнаты включает весь свет.

## Как это работает

- Одна короткая сессия на запрос (согласование ключа сессии: nonce, HMAC-SHA256, XOR, AES-GCM), чтобы оставался слот для приложения Smart Life; запросы к одной лампочке идут по очереди.
- Датапоинты лампы категории `dj`: `20` питание, `21` режим (`white`/`colour`), `22` яркость 10..1000, `24` цвет `hhhhssssvvvv`.
- `saturation: 0` возвращает лампочку в обычный белый режим. Яркость меньше 1% лампочка не поддерживает (минимум 10 из 1000).
- Лампочка, которая не ответила, пару секунд не опрашивается повторно, чтобы список не тормозил.
- Если смена `local key` (лампочку удалили и добавили заново в приложении), клиент пишет «wrong local key»: получи ключ заново шагом 1.
