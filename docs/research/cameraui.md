## Как изучалось и что это значит

- **REA** (`capture_browser_scenario`, Chrome в режиме запуска, дерево доступности страницы): снята главная страница сайта. Evidence `ev_5263f8c954f7cb2a626acb117cefde5dbd10b0584a6e14b108f22917ceaf0806`. Это **наблюдение за публичной страницей**: список функций, цены и сравнение с конкурентами. Это то, что проект сам о себе заявляет, а не проверка работы приложения.
- **Документация** (`docs.cameraui.com`, страницы о зонах и о детекции движения) прочитана обычным способом через `WebFetch`, не через REA: это текст, а не собранный артефакт.
- **Код не изучался и не копировался.** Репозиторий `github.com/cameraui/camera.ui` под лицензией MIT (`Copyright (c) 2020-present seydx`), но реализации в этом проекте написаны заново под нашу архитектуру. Если когда-нибудь будет взят код оттуда, нужно сохранить текст лицензии и авторство.
- Не проверено: демо `demo.cameraui.com`, работа приложения, реальные алгоритмы. Всё ниже про устройство camera.ui взято со страниц сайта и документации.

## Что у них есть и как это соотносится с нашим проектом

| Возможность camera.ui | У нас | Решение |
|-----------------------|-------|---------|
| Зоны движения (где движение считается), игнорируемые области | нет | **Сделано** ([ADR 0008](../adr/0008-motion-zones.md)): прямоугольные зоны «игнорировать/только здесь» |
| Подсказка в их документации: **вшитая в картинку метка времени камеры может давать ложное движение**, особенно ночью; решение: зона движения без угла с меткой | нет | Учтено: заготовки «углы» в окне зон. Проверить, печатает ли ваша камера время в картинке (водяной знак включается в Xiaomi Home) |
| «Трассировка детекции»: каждое решение объяснено покадрово | только число `level` | **Сделано в упрощённом виде:** живая шкала уровня с отметкой порога в окне зон |
| Таймаут движения (минимум 10 с): «активность» держится после остановки | `quietSec` = 8 | Уже есть. Стоит рассмотреть минимум |
| Эпизоды: «не 14 клипов, а одна история» | список клипов | Группировка близких по времени клипов: дёшево, снижает шум |
| Хранилище: правила хранения, лимит размера, статистика | возраст + лимит ГБ + `storage` в API | Основа есть; показать в интерфейсе |
| Логи, метрики, терминал в приложении | логи в файлах | Панель «состояние системы» (go2rtc, ffmpeg, потери пакетов, диск) |
| Приватные зоны (чёрные области на снимках, превью, в живом виде) | нет | **Сделано** ([ADR 0011](../adr/0011-privacy-zones.md)): чёрное в живом виде, снимках и превью; записи не меняются |
| Зоны объектов, зоны оповещений, пересечение линии | нет | Требует распознавания объектов |
| Распознавание людей, машин, лиц, номеров; шесть AI-бэкендов | нет | **Сделано как метки и фильтр** ([ADR 0012](../adr/0012-object-detection.md)): YOLOX-Tiny, Apache-2.0 |
| Семантический поиск, описания ИИ, ассистент, MCP | нет | Позже |
| Зашифрованные пуши с видео | пуши без картинки (ADR 0005) | Позже, после мобильного приложения |
| Общий доступ к камере по ссылке, удалённый доступ без проброса портов | нет (Tailscale в плане) | Позже |
| Планы дома, датчики, автоматизации, HomeKit, Home Assistant | нет | Не нужно сейчас |

## Порядок внедрения (предложение)

1. Зоны движения (игнорировать/следить) + живая шкала уровня: **сделано** ([ADR 0008](../adr/0008-motion-zones.md)).
2. Панель «состояние системы» (go2rtc, ffmpeg, повреждённая картинка, диск): **сделано** ([ADR 0009](../adr/0009-system-panel.md)).
3. Группировка клипов в эпизоды и фильтр по дню: **сделано** ([ADR 0010](../adr/0010-episodes-and-day-filter.md)).
4. Распознавание людей, машин и животных: **сделано как метки и фильтр** ([ADR 0012](../adr/0012-object-detection.md)); автоматическое удаление пустых клипов не включено по вашему выбору.
5. Приватные зоны на снимках и превью: **сделано** ([ADR 0011](../adr/0011-privacy-zones.md)).
