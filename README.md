# Камера Xiaomi: мониторинг, PTZ и запись по движению

Домашнее приложение для камеры Xiaomi (PTZ 2K). Видео и управление идут напрямую с камеры в вашей сети, облако Xiaomi для работы приложения не нужно.

**Что умеет**
- Живое видео (WebRTC, HLS, кадры), поворот камеры, снимки.
- Запись клипов по движению с запасом до и после; клипы собираются в **эпизоды**, есть фильтр по дню.
- **Распознавание людей, машин и животных** на клипах (метки и фильтр), клипы не удаляются.
- **Зоны движения** (игнорировать метку времени, дерево, дорогу) и **приватные зоны** (чёрное в живом виде, снимках и превью).
- Раздел **System**: что с go2rtc, картинкой, диском и пушами, простыми словами.
- Пуш-уведомления (сервер готов, мобильное приложение впереди).
- Защита: токен только в заголовке, подписанные ссылки на файлы, блокировка подбора, строгая CSP.

План и состояние: [ROADMAP.md](ROADMAP.md). Принятые решения: [docs/README.md](docs/README.md).

## Запуск одной командой

```bash
./camera.sh
```

Скрипт сам запускает go2rtc и бэкенд, ждёт, пока они ответят, печатает адреса и показывает логи. **Ctrl+C останавливает всё**, что он запустил.
Хватит одного терминала. Если терминал не нужен совсем, `./camera.sh up` запускает всё в фоне и возвращает управление.

| Команда | Что делает |
|---------|------------|
| `./camera.sh` | запустить всё и следить за логами (Ctrl+C остановит) |
| `./camera.sh up` | запустить в фоне и вернуться |
| `./camera.sh stop` | остановить то, что запустил скрипт |
| `./camera.sh restart` | перезапустить всё в фоне (go2rtc тоже: камера переподключается) |
| `./camera.sh restart backend` | перезапустить только сервер, go2rtc и камеру не трогать (после правок кода) |
| `./camera.sh status` | что работает и по каким адресам |
| `./camera.sh logs` | следить за логами (`logs/go2rtc.log`, `logs/backend.log`) |
| `./camera.sh motor left` | повернуть камеру руками (`left`, `right`, `up`, `down`) |
| `./camera.sh build-motor` | собрать go2rtc с поддержкой поворота (нужны git и Go ≥ 1.26) |
| `./camera.sh fetch-model` | один раз скачать модель распознавания людей и животных (YOLOX-M, ~97 МБ, Apache-2.0) |
| `./camera.sh label-clips` | добавить метки «человек / машина / животное» старым клипам |

Скрипт безопасно запускать повторно: уже работающие go2rtc или бэкенд (даже запущенные вами в другом терминале) он использует и не трогает.
Останавливает он только то, что запустил сам. Решение описано в [ADR 0006](docs/adr/0006-single-launcher.md).

### Что нужно один раз
1. Node 22 или новее; `brew install ffmpeg` (для снимков и записи по движению).
2. `./camera.sh build-motor`: собирает `go2rtc-motor`, если его ещё нет.
3. `backend/.env`: скопируйте `backend/.env.example` и впишите `API_TOKEN` (`openssl rand -hex 24`).
4. `go2rtc.yaml` с потоком камеры (появляется после входа в Mi Home в веб-интерфейсе go2rtc, http://127.0.0.1:1984).
5. По желанию `./camera.sh fetch-model`: модель для меток «человек / машина / животное» (без неё всё остальное работает).

Зависимости бэкенда и сборку веб-приложения скрипт при первом запуске сделает сам. Откройте http://localhost:3100 и введите `API_TOKEN`.

## Устройство

```
Камера Xiaomi ──P2P──> go2rtc-motor (127.0.0.1) ──> backend (Fastify, :3100) ──> веб-приложение (React)
                                                      ├─ ffmpeg: запись по движению, зоны
                                                      ├─ YOLOX-M (onnxruntime): метки на клипах
                                                      └─ пуши через Expo
```

| Папка или файл | Что это |
|----------------|---------|
| `camera.sh` | запуск и остановка всего приложения |
| `backend/` | API, запись по движению, пуши ([README](backend/README.md)) |
| `web/` | веб-приложение ([README](web/README.md)), собирается в `backend/public` |
| `go2rtc.yaml`, `motor-xiaomi.patch`, `cs2-queue.patch` | поток камеры, патч для поворота и патч увеличенной очереди пакетов (против `cs2: pop buffer is full`) |
| `docs/` | принятые решения (ADR), исследования ([индекс](docs/README.md)) |
| `ROADMAP.md` | что сделано и что дальше |

## Безопасность в двух строках
Токен принимается только в заголовке, файлы открываются по подписанным ссылкам, неверные токены блокируют адрес, по умолчанию бэкенд слушает только этот Mac.
Подробности: [ADR 0001](docs/adr/0001-signed-media-urls.md), [ADR 0002](docs/adr/0002-auth-lockout-and-security-headers.md), [ADR 0003](docs/adr/0003-motion-lighting-filter-storage-limit-localhost.md).
Приватные зоны скрывают область в живом виде, снимках и превью, но **не в записанных клипах** ([ADR 0011](docs/adr/0011-privacy-zones.md)).
`go2rtc.yaml` содержит токен вашего аккаунта Xiaomi: не коммитьте и не показывайте его.
